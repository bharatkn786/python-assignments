# Week 1 - Lab 3: Git and GitHub Workflow

## Overview

This lab focuses on practicing a real-world Git and GitHub workflow using feature branches, multiple commits, pull requests, code reviews, follow-up commits, and merging.

The Week 1 Lab 2 code was used to practice this workflow.

---

## Git Workflow Followed

```text
main
  │
  └── feature/word-count
          │
          ├── Task 1 - Word Count
          ├── Task 2 - Using Counter
          ├── Task 3 - Flatten Nested List
          ├── Task 4 - Flatten Using Comprehension
          ├── Task 5 - Mean Using numbers.txt
          └── Task 6 - README
                  │
                  ▼
             Pull Request
                  │
                  ▼
              Code Review
                  │
                  ▼
           Review Feedback
                  │
                  ▼
           Follow-up Commit
                  │
                  ▼
                Merge
                  │
                  ▼
                main

```
